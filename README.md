# COB's Workspace

Single-file personal workspace (`index.html`): weekly to-dos, CEO tasks, meetings, initiatives, decisions & risks, objectives & achievements (promotion case), people.

## Deploy on GitHub Pages
1. Create a new GitHub repo (use **Private** if your plan supports private Pages, otherwise keep nothing sensitive in the repo — your data is never stored in it).
2. Upload `index.html` (drag & drop on the repo page → Commit).
3. Repo **Settings → Pages → Build from branch → `main` / root → Save**.
4. Open `https://<your-username>.github.io/<repo>/`.

## Your data
Stored in your browser's localStorage (per browser/device, never sent anywhere).
Use **Export backup** regularly; **Import backup** to move to another browser/device.

## Importing your Google Calendar
1. Google Calendar → Settings → *Import & export* → **Export** → unzip, take your `.ics` file.
2. In the app: **Meetings → Import calendar (.ics)**.
3. Open any meeting to add notes and tasks. Re-importing adds new meetings only; notes are kept.
(Recurring meetings are expanded for the last 60 / next 120 days.)

## Tips
- Tasks added inside a meeting move to your task list when you save the meeting.
- Attendees are added to People when you save a meeting.
- Tick a task or set its status to *Completed* and it moves to the **Completed** archive, grouped by month.
